## Application rules
- Keep the executive demo client-side with shared synthetic data and deterministic simulated scoring; no real patient or physician data is processed.
- Use leaf routes for each intelligence view and shared navigation around the root outlet so all demo screens can be bookmarked.
- Define visual roles in the global design system and reusable chart components so analytics stay consistent across views.
